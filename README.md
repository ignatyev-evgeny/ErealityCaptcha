# Ereality Captcha Resolver

Бот для автоматического решения капчи на проекте [Ereality.ru](https://ereality.ru/), с управлением через Telegram.

---

## 🚀 Возможности
- Авторизация в Ereality по логину и паролю.
- Автоматическое обнаружение и решение капчи.
- Отправка скриншота капчи в Telegram-бот.
- Ожидание текстового ответа от пользователя для капчи.
- Повторная авторизация при разлогине.
- Управление через команды `/screen` (сделать скриншот) и `/click` (клик по нужной области).
- Плавный трекер координат мыши в iframe для помощи в настройке.

---

## 🛠 Установка

1. Установите зависимости:

    ```bash
    go get github.com/chromedp/chromedp
    go get github.com/joho/godotenv
    go get fyne.io/fyne/v2
    ```

2. Подготовьте файл `.env` в корне проекта:

    ```env
    BOT_TOKEN=ваш_токен_бота
    ```

3. Подготовьте файл `settings.json`:

    ```json
    {
      "login": "ваш_логин",
      "password": "ваш_пароль",
      "chat_id": "ваш_чат_id"
    }
    ```

4. Соберите и запустите проект:

    ```bash
    go run .
    ```

## 📍 Использование трекера координат

### Как получить координаты для кликов по карте:

1. Откройте страницу Ereality в браузере.
2. Найдите `iframe`, где отображается карта.
3. Откройте **инструменты разработчика** (DevTools) в браузере:
    - Нажмите `F12` или `Ctrl+Shift+I`.
4. Перейдите на вкладку **Console**.
5. Откройте папку проекта `/assets/` и скопируйте содержимое файла `track-coordinates.js`.
6. Вставьте скопированный код в консоль и нажмите **Enter**.
7. Теперь рядом с курсором будет отображаться окно с координатами `X: ... | Y: ...`.
8. Наведите курсор на нужное место на карте.
9. Запишите координаты, которые будут отображены — они нужны для настройки точек кликов или решения капчи.

> **Важно:** Координаты отображаются относительно карты внутри iframe.

## 📢 Команды Telegram бота

| Команда    | Описание                                     |
|:-----------|:---------------------------------------------|
| `/screen`  | Сделать скриншот текущего состояния игры.     |
| `/click`   | Выполнить клик по заранее настроенной области карты. |

## ❗ Важные замечания
- Обязательно добавьте `.env` в `.gitignore`, чтобы токен Telegram-бота не попал в публичные репозитории.
- Chrome запускается в **не headless-режиме** (`headless: false`), чтобы видеть, что происходит в браузере.
- При использовании нескольких фреймов на странице убедитесь, что скрипт подключается к нужному `iframe`.
